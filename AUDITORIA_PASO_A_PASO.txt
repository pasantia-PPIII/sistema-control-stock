1. QUÉ SE VA A AUDITAR
---------------------------------------------------------------------
 Pregunta que debe poder contestar la auditoría: ¿QUIÉN hizo QUÉ,
 CUÁNDO, DESDE DÓNDE y CÓMO ESTABA ANTES?

 A) ACCESOS AL SISTEMA (tabla auditoria_acceso)
    - Ingreso correcto, ingreso fallido, bloqueo por intentos y cierre
      de sesión. Se guarda el DNI tipeado (aunque no exista), la IP y
      el navegador.

 B) CAMBIOS EN REGISTROS (tabla auditoria_cambio)
    - Cargas (altas), ediciones, deshabilitaciones, habilitaciones,
      anulaciones y reactivaciones de: insumos, movimientos, órdenes de
      trabajo, operarios, rubros y usuarios, más los cambios de
      contraseña (sin guardar la contraseña).
    - En las ediciones se guarda SOLO lo que cambió, con el valor
      anterior y el nuevo.
    - "Eliminaciones": el sistema no borra nada, así que las bajas son
      DESHABILITAR / ANULAR y quedan registradas como tales.

 C) CAMBIOS DE STOCK (tabla auditoria_stock): el "libro de stock"
    - Cada vez que cambia la cantidad de un insumo: stock anterior,
      stock nuevo, diferencia, quién y de dónde vino el cambio:
        ALTA_INSUMO            stock inicial al crear el insumo
        EDICION_INSUMO         carga de mercadería, recuento o corrección
                               manual desde Insumos > Editar
        MOVIMIENTO             entrega o devolución (queda ligada al
                               movimiento)
        ANULACION_MOVIMIENTO   reversión al anular un movimiento
    - Las herramientas también: su stock pasa de 1 a 0 (prestada) y de
      0 a 1 (devuelta Disponible).
    - Regla de oro: el stock final de un insumo siempre es igual al
      "stock nuevo" de su último registro. La prueba lo verificó.

 Reglas de diseño (por qué está hecho así):
   1. Solo se inserta y se consulta. Nunca se edita ni se borra
      (triggers en la base lo impiden).
   2. El cambio y su auditoría se guardan en la MISMA transacción: o
      quedan los dos o no queda ninguno. No puede haber un cambio sin
      rastro.
   3. Si no hay usuario con sesión, no se deja cambiar nada (error).
      Excepción: los accesos, que nunca bloquean el ingreso.
   4. Nunca se guardan contraseñas ni sus hashes (la clase los quita
      sola de cualquier dato).
   5. Si "guardar" no cambió nada, no se registra nada (sin ruido).
   6. Quién ve la auditoría: solo los roles ADMINISTRADOR y VISTA. El
      pañolero no ve ni la pestaña, ni los datos (el servidor responde
      "sin permiso" aunque conozca la dirección).
   7. Todo lo que se muestra en pantalla se escapa (un nombre con
      <script> o comillas no puede romper la página).
   8. Las horas salen de la base de datos (zona horaria Argentina).

        -- AUDITORÍA: accesos, cambios en registros y cambios de stock
        -- =========================================================
        -- Ejecutar UNA vez (si las tablas ya existen no hace nada).
        --   psql -U postgres -d db_control_stock -f bd/migracion_auditoria.sql
        -- Requiere PostgreSQL 11 o superior.

        -- ---------------------------------------------------------
        -- 1) Accesos al sistema (ingresos, intentos fallidos, bloqueos y cierres de sesión)
        -- ---------------------------------------------------------
        -- No lleva clave foránea a usuario: se registra el DNI tipeado aunque no exista.
        CREATE TABLE IF NOT EXISTS auditoria_acceso (
            id_acceso   BIGSERIAL PRIMARY KEY,
            fecha_hora  TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
            dni         VARCHAR(20)  NOT NULL,
            evento      VARCHAR(20)  NOT NULL
                        CHECK (evento IN ('LOGIN_OK', 'LOGIN_FALLIDO', 'LOGIN_BLOQUEADO', 'LOGOUT')),
            ip          VARCHAR(45),
            user_agent  VARCHAR(255)
        );
        CREATE INDEX IF NOT EXISTS idx_aud_acceso_fecha ON auditoria_acceso (fecha_hora DESC);
        CREATE INDEX IF NOT EXISTS idx_aud_acceso_dni   ON auditoria_acceso (dni, fecha_hora DESC);

        -- ---------------------------------------------------------
        -- 2) Cambios en registros (cargas, ediciones, deshabilitaciones, anulaciones...)
        -- ---------------------------------------------------------
        -- datos_anteriores / datos_nuevos guardan SOLO los campos que cambiaron (en una carga, el registro
        -- completo en datos_nuevos). Nunca se guardan contraseñas.
        CREATE TABLE IF NOT EXISTS auditoria_cambio (
            id_cambio        BIGSERIAL PRIMARY KEY,
            fecha_hora       TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
            dni_usuario      VARCHAR(20)   NOT NULL REFERENCES usuario(dni),
            accion           VARCHAR(20)   NOT NULL
                             CHECK (accion IN ('CREAR', 'EDITAR', 'DESHABILITAR', 'HABILITAR',
                                               'ANULAR', 'REACTIVAR', 'CAMBIAR_CONTRASENA')),
            entidad          VARCHAR(30)   NOT NULL,   -- insumo, movimiento, orden_de_trabajo, operario, rubro, usuario
            id_registro      VARCHAR(50)   NOT NULL,   -- id, código o DNI del registro afectado
            descripcion      VARCHAR(500)  NOT NULL,   -- frase legible: "Insumo 24001: stock 12 -> 30"
            datos_anteriores JSONB,
            datos_nuevos     JSONB,
            ip               VARCHAR(45)
        );
        CREATE INDEX IF NOT EXISTS idx_aud_cambio_fecha    ON auditoria_cambio (fecha_hora DESC);
        CREATE INDEX IF NOT EXISTS idx_aud_cambio_usuario  ON auditoria_cambio (dni_usuario, fecha_hora DESC);
        CREATE INDEX IF NOT EXISTS idx_aud_cambio_registro ON auditoria_cambio (entidad, id_registro, fecha_hora DESC);

        -- ---------------------------------------------------------
        -- 3) Cambios de stock (libro de stock: valor anterior, valor nuevo y de dónde salió)
        -- ---------------------------------------------------------
        CREATE TABLE IF NOT EXISTS auditoria_stock (
            id_auditoria_stock BIGSERIAL PRIMARY KEY,
            fecha_hora         TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
            dni_usuario        VARCHAR(20)   NOT NULL REFERENCES usuario(dni),
            id_insumo          INT           NOT NULL REFERENCES insumos(id_insumo),
            stock_anterior     NUMERIC(10,2) NOT NULL,
            stock_nuevo        NUMERIC(10,2) NOT NULL,
            origen             VARCHAR(25)   NOT NULL
                               CHECK (origen IN ('ALTA_INSUMO', 'EDICION_INSUMO', 'MOVIMIENTO', 'ANULACION_MOVIMIENTO')),
            id_movimiento      INT           REFERENCES movimiento(id_movimiento),
            detalle            VARCHAR(255)
        );
        CREATE INDEX IF NOT EXISTS idx_aud_stock_fecha  ON auditoria_stock (fecha_hora DESC);
        CREATE INDEX IF NOT EXISTS idx_aud_stock_insumo ON auditoria_stock (id_insumo, fecha_hora DESC);

        -- ---------------------------------------------------------
        -- 4) Protección: las tablas de auditoría solo se pueden insertar y consultar
        -- ---------------------------------------------------------
        CREATE OR REPLACE FUNCTION auditoria_solo_insertar() RETURNS trigger AS $$
        BEGIN
            RAISE EXCEPTION 'La tabla % es de auditoría: no se puede modificar ni borrar.', TG_TABLE_NAME;
        END;
        $$ LANGUAGE plpgsql;

        DO $$
        DECLARE
            t TEXT;
        BEGIN
            FOREACH t IN ARRAY ARRAY['auditoria_acceso', 'auditoria_cambio', 'auditoria_stock'] LOOP
                EXECUTE format('DROP TRIGGER IF EXISTS trg_%I_inmutable ON %I', t, t);
                EXECUTE format('CREATE TRIGGER trg_%I_inmutable BEFORE UPDATE OR DELETE ON %I
                                FOR EACH ROW EXECUTE FUNCTION auditoria_solo_insertar()', t, t);
                EXECUTE format('DROP TRIGGER IF EXISTS trg_%I_sin_truncate ON %I', t, t);
                EXECUTE format('CREATE TRIGGER trg_%I_sin_truncate BEFORE TRUNCATE ON %I
                                FOR EACH STATEMENT EXECUTE FUNCTION auditoria_solo_insertar()', t, t);
            END LOOP;
        END
        $$;

PASO 2 - LA CLASE DE AUDITORÍA
---------------------------------------------------------------------
 ARCHIVO NUEVO: clases/auditoria.php

        <?php
        /**
         * clases/auditoria.php
         * Registro de auditoría del sistema: accesos, cambios en registros y cambios de stock.
         *
         * - Solo se INSERTA y se CONSULTA: nunca se actualiza ni se borra (lo refuerzan los triggers de
         *   bd/migracion_auditoria.sql).
         * - Escribe con la misma conexión que el resto del sistema (Database), por lo que cuando se llama dentro
         *   de una transacción el registro de auditoría se confirma o se deshace junto con el cambio.
         * - Los métodos registrarCambio() y registrarStock() LANZAN excepción si fallan (un cambio sin auditoría
         *   no debe quedar guardado). registrarAcceso() nunca lanza: un fallo de auditoría no impide ingresar.
         */
        require_once __DIR__ . '/../config/database.php';

        class Auditoria
        {
            // Eventos de acceso
            const LOGIN_OK        = 'LOGIN_OK';
            const LOGIN_FALLIDO   = 'LOGIN_FALLIDO';
            const LOGIN_BLOQUEADO = 'LOGIN_BLOQUEADO';
            const LOGOUT          = 'LOGOUT';

            // Acciones sobre registros
            const CREAR              = 'CREAR';
            const EDITAR             = 'EDITAR';
            const DESHABILITAR       = 'DESHABILITAR';
            const HABILITAR          = 'HABILITAR';
            const ANULAR             = 'ANULAR';
            const REACTIVAR          = 'REACTIVAR';
            const CAMBIAR_CONTRASENA = 'CAMBIAR_CONTRASENA';

            // Origen de un cambio de stock
            const STOCK_ALTA       = 'ALTA_INSUMO';
            const STOCK_EDICION    = 'EDICION_INSUMO';
            const STOCK_MOVIMIENTO = 'MOVIMIENTO';
            const STOCK_ANULACION  = 'ANULACION_MOVIMIENTO';

            // Listas para los filtros de la pantalla
            const EVENTOS  = [self::LOGIN_OK, self::LOGIN_FALLIDO, self::LOGIN_BLOQUEADO, self::LOGOUT];
            const ACCIONES = [self::CREAR, self::EDITAR, self::DESHABILITAR, self::HABILITAR,
                              self::ANULAR, self::REACTIVAR, self::CAMBIAR_CONTRASENA];
            const ORIGENES = [self::STOCK_ALTA, self::STOCK_EDICION, self::STOCK_MOVIMIENTO, self::STOCK_ANULACION];

            // Campos que nunca se guardan en datos_anteriores / datos_nuevos
            private const CAMPOS_SECRETOS = ['contrasena', 'password', 'csrf_token'];

            // =========================================================
            // 1. ESCRITURA
            // =========================================================

            /**
             * Registra un acceso (ingreso correcto, ingreso fallido, bloqueo o cierre de sesión).
             * Nunca lanza excepción.
             * @param string $evento Una de las constantes LOGIN_* / LOGOUT
             * @param string $dni DNI tipeado o de la sesión (puede no existir como usuario)
             */
            public static function registrarAcceso(string $evento, string $dni): void
            {
                try {
                    Database::execute(
                        "INSERT INTO auditoria_acceso (dni, evento, ip, user_agent) VALUES (:dni, :evento, :ip, :ua)",
                        [
                            'dni'    => substr(trim($dni), 0, 20),
                            'evento' => $evento,
                            'ip'     => self::ip(),
                            'ua'     => self::texto($_SERVER['HTTP_USER_AGENT'] ?? '', 255),
                        ]
                    );
                } catch (Throwable $e) {
                    error_log('Auditoría (acceso): ' . $e->getMessage());
                }
            }

            /**
             * Registra un cambio sobre un registro (carga, edición, deshabilitación, anulación...).
             * Usa el usuario de la sesión. Lanza excepción si no hay sesión o si falla el INSERT.
             *
             * @param string $accion Una de las constantes de acción (CREAR, EDITAR, ...)
             * @param string $entidad insumo | movimiento | orden_de_trabajo | operario | rubro | usuario
             * @param int|string $idRegistro Id, código o DNI del registro afectado
             * @param string $descripcion Frase legible para la pantalla
             * @param array|null $antes Valores anteriores (solo los campos que cambiaron)
             * @param array|null $despues Valores nuevos (en una carga, el registro completo)
             */
            public static function registrarCambio(string $accion, string $entidad, $idRegistro, string $descripcion,
                                                   ?array $antes = null, ?array $despues = null): void
            {
                Database::execute(
                    "INSERT INTO auditoria_cambio (dni_usuario, accion, entidad, id_registro, descripcion, datos_anteriores, datos_nuevos, ip)
                     VALUES (:dni, :accion, :entidad, :id, :descripcion, CAST(:antes AS jsonb), CAST(:despues AS jsonb), :ip)",
                    [
                        'dni'         => self::dniSesion(),
                        'accion'      => $accion,
                        'entidad'     => $entidad,
                        'id'          => (string)$idRegistro,
                        'descripcion' => self::texto($descripcion, 500) ?? '',
                        'antes'       => self::aJson($antes),
                        'despues'     => self::aJson($despues),
                        'ip'          => self::ip(),
                    ]
                );
            }

            /**
             * Registra un cambio de stock de un insumo (valor anterior -> valor nuevo).
             * Si el stock no cambió no se registra nada, salvo en el alta del insumo (siempre queda el stock inicial).
             *
             * @param int $idInsumo Insumo afectado
             * @param float $anterior Stock antes del cambio
             * @param float $nuevo Stock después del cambio
             * @param string $origen Una de las constantes STOCK_*
             * @param int|null $idMovimiento Movimiento que lo originó (entrega, devolución o su anulación)
             * @param string|null $detalle Texto opcional
             */
            public static function registrarStock(int $idInsumo, float $anterior, float $nuevo, string $origen,
                                                  ?int $idMovimiento = null, ?string $detalle = null): void
            {
                if ($origen !== self::STOCK_ALTA && abs($nuevo - $anterior) < 0.0001) {
                    return;
                }
                Database::execute(
                    "INSERT INTO auditoria_stock (dni_usuario, id_insumo, stock_anterior, stock_nuevo, origen, id_movimiento, detalle)
                     VALUES (:dni, :insumo, :anterior, :nuevo, :origen, :mov, :detalle)",
                    [
                        'dni'      => self::dniSesion(),
                        'insumo'   => $idInsumo,
                        'anterior' => (string)$anterior,
                        'nuevo'    => (string)$nuevo,
                        'origen'   => $origen,
                        'mov'      => $idMovimiento,
                        'detalle'  => self::texto($detalle ?? '', 255),
                    ]
                );
            }

            /**
             * Compara dos versiones de un registro y devuelve solo los campos que cambiaron.
             * Se recorren los campos de $despues (lo que realmente se está guardando).
             * @return array [antes, despues]; ambos vacíos si no hubo cambios
             */
            public static function diferencias(array $antes, array $despues): array
            {
                $a = [];
                $d = [];
                foreach ($despues as $campo => $valorNuevo) {
                    if (in_array($campo, self::CAMPOS_SECRETOS, true)) {
                        continue;
                    }
                    $valorViejo = $antes[$campo] ?? null;
                    if (self::normalizar($valorViejo) !== self::normalizar($valorNuevo)) {
                        $a[$campo] = $valorViejo;
                        $d[$campo] = $valorNuevo;
                    }
                }
                return [$a, $d];
            }

            /**
             * Ejecuta $fn dentro de una transacción (la abre solo si no hay una abierta) para que el cambio y su
             * registro de auditoría se guarden juntos o no se guarde ninguno.
             * NO usar en métodos que ya abren su propia transacción (Movimiento::create/anular, Insumo::create/update,
             * OrdenDeTrabajo::create/update...): ahí se llama a Auditoria::registrar...() dentro de la existente.
             */
            public static function transaccion(callable $fn)
            {
                $pdo = Database::getConnection();
                $propia = !$pdo->inTransaction();
                if ($propia) {
                    $pdo->beginTransaction();
                }
                try {
                    $resultado = $fn();
                    if ($propia) {
                        $pdo->commit();
                    }
                    return $resultado;
                } catch (Throwable $e) {
                    if ($propia && $pdo->inTransaction()) {
                        $pdo->rollBack();
                    }
                    throw $e;
                }
            }

            public static function getStock(array $f, int $limite = 25, int $offset = 0): array

            }

            private static function filtrosAcceso(array $f): array
            {
                $where = [];
                $params = [];
                self::rangoFechas($f, 'a.fecha_hora', $where, $params);
                if (!empty($f['evento']) && in_array($f['evento'], self::EVENTOS, true)) {
                    $where[] = 'a.evento = :evento';
                    $params['evento'] = $f['evento'];
                }
                if (!empty($f['busqueda'])) {
                    $where[] = "(a.dni ILIKE :b1 OR a.ip ILIKE :b2 OR u.nombre ILIKE :b3 OR u.apellido ILIKE :b4)";
                    $like = '%' . $f['busqueda'] . '%';
                    $params += ['b1' => $like, 'b2' => $like, 'b3' => $like, 'b4' => $like];
                }
                return [self::armarWhere($where), $params];
            }

            private static function filtrosCambio(array $f): array
            {
                $where = [];
                $params = [];
                self::rangoFechas($f, 'c.fecha_hora', $where, $params);
                if (!empty($f['accion']) && in_array($f['accion'], self::ACCIONES, true)) {
                    $where[] = 'c.accion = :accion';
                    $params['accion'] = $f['accion'];
                }
                if (!empty($f['entidad'])) {
                    $where[] = 'c.entidad = :entidad';

                }
                if (!empty($f['busqueda'])) {
                    $where[] = "(c.dni_usuario ILIKE :b1 OR c.id_registro ILIKE :b2 OR c.descripcion ILIKE :b3
                                 OR u.nombre ILIKE :b4 OR u.apellido ILIKE :b5)";
                    $like = '%' . $f['busqueda'] . '%';
                    $params += ['b1' => $like, 'b2' => $like, 'b3' => $like, 'b4' => $like, 'b5' => $like];
                }

            }

            /** Rango de fechas inclusivo (el día "hasta" entra completo). Las fechas con formato inválido se ignoran. */
            private static function rangoFechas(array $f, string $columna, array &$where, array &$params): void
            {
                if (!empty($f['desde']) && preg_match('/^\d{4}-\d{2}-\d{2}$/', $f['desde'])) {
                    $where[] = "$columna >= CAST(:desde AS date)";
                    $params['desde'] = $f['desde'];
                }
                if (!empty($f['hasta']) && preg_match('/^\d{4}-\d{2}-\d{2}$/', $f['hasta'])) {
                    $where[] = "$columna < CAST(:hasta AS date) + 1";
                    $params['hasta'] = $f['hasta'];
                }
            }

            private static function armarWhere(array $where): string
            {
                return $where ? ' WHERE ' . implode(' AND ', $where) : '';
            }

                }

            }

            {
                if ($datos === null) {

            }

            private static function normalizar($valor): string
            {
                if ($valor === null) {
                    return '';
                }
                if (is_bool($valor)) {
                    return $valor ? '1' : '0';
                }
                if (is_numeric($valor)) {
                    return (string)(float)$valor;
                }
                return trim((string)$valor);
            }

        /**
         * Una página de las vistas nuevas de auditoría ('accesos', 'cambios' o 'stock'), lista para json_encode().
         */
        function auditoriaPagina(string $vista, array $filtros, int $pagina): array
        {
            $porPagina = 25;

            $total = match ($vista) {
                'accesos' => Auditoria::contarAccesos($filtros),
                'cambios' => Auditoria::contarCambios($filtros),
                'stock'   => Auditoria::contarStock($filtros),
                default   => throw new InvalidArgumentException('Vista de auditoría no válida.'),
            };

            $totalPaginas = max(1, (int)ceil($total / $porPagina));
            $pagina = max(1, min($pagina, $totalPaginas));
            $offset = ($pagina - 1) * $porPagina;

            $datos = match ($vista) {
                'accesos' => Auditoria::getAccesos($filtros, $porPagina, $offset),
                'cambios' => Auditoria::getCambios($filtros, $porPagina, $offset),
                'stock'   => Auditoria::getStock($filtros, $porPagina, $offset),
            };

            return [
                'data'            => $datos,
                'total_registros' => $total,
                'total_paginas'   => $totalPaginas,
                'pagina_actual'   => $pagina,
            ];

 Cómo queda la pestaña (solo la ven Administrador y Vista):

   Reportes > [ Alerta Stock Mínimo ]  [ Auditoría ]
   Auditoría:
     Tarjetas (últimos 30 días): Ingresos correctos | Ingresos fallidos |
                                 Cambios en registros | Cambios de stock
     Sub-pestañas: [Movimientos] [Accesos al sistema]
                   [Cambios en registros] [Cambios de stock]
       Movimientos           = la tabla de auditoría que ya existía,
                               tal cual (se mueve adentro, sin cambios)
       Accesos al sistema    = fecha | usuario | evento | IP | navegador
       Cambios en registros  = fecha | usuario | acción | registro |
                               descripción | botón "Ver" que despliega la
                               tabla campo / antes / después
       Cambios de stock      = fecha | usuario | insumo | anterior | nuevo
                               | diferencia (rojo/verde) | origen (con
                               enlace al movimiento)
     Las tres nuevas comparten: Desde, Hasta, un filtro propio
     (evento / acción / origen), buscador de texto, Filtrar, Limpiar y
     paginación de 25 en 25.

        // Convierte un mapa de etiquetas en { clave: texto } para armar el <select> del filtro
        function audOpciones(mapa) {
            const o = {};
            Object.keys(mapa).forEach(k => { o[k] = Array.isArray(mapa[k]) ? mapa[k][0] : mapa[k]; });
            return o;
        }

        function audBadge(mapa, clave) {
            const e = mapa[clave] || [clave, 'neutral'];
            return `<span class="aud-badge ${escaparHtml(e[1])}">${escaparHtml(e[0])}</span>`;
        }
        function audFecha(v) { return v ? escaparHtml(String(v).substring(0, 19)) : '-'; }
        function audUsuario(dni, nombre) {
            return `<strong>${escaparHtml(dni)}</strong>` + (nombre ? `<br><small>${escaparHtml(nombre)}</small>` : '');
        }
        function audValor(v) {
            if (v === null || v === undefined) return '—';
            if (v === true) return 'Sí';
            if (v === false) return 'No';
            if (typeof v === 'object') return JSON.stringify(v);
            return String(v);
        }

        // Tabla "campo | antes | después" de un cambio
        function audTablaDiff(antes, despues) {
            const a = antes || {};
            const d = despues || {};
            const campos = Array.from(new Set(Object.keys(a).concat(Object.keys(d))));
            if (campos.length === 0) return '<em>Sin datos adicionales.</em>';
            let html = '<table class="aud-diff"><thead><tr><th>Campo</th><th>Antes</th><th>Después</th></tr></thead><tbody>';
            campos.forEach(c => {
                html += `<tr><td><strong>${escaparHtml(c)}</strong></td>` +
                        `<td class="antes">${escaparHtml(audValor(a[c]))}</td>` +
                        `<td class="despues">${escaparHtml(audValor(d[c]))}</td></tr>`;
            });
            return html + '</tbody></table>';
        }

        let audSub = 'movimientos';

        // Cambia entre las cuatro sub-pestañas
        function cambiarSubAuditoria(sub) {
            audSub = sub;
            document.querySelectorAll('.aud-subtab').forEach(b => b.classList.toggle('active', b.dataset.sub === sub));
            document.getElementById('aud-sub-movimientos').style.display = (sub === 'movimientos') ? 'block' : 'none';
            document.getElementById('aud-sub-nuevas').style.display = (sub === 'movimientos') ? 'none' : 'block';
            if (sub === 'movimientos') return;

            const cfg = AUD_VISTAS[sub];
            document.getElementById('aud-busqueda').placeholder = cfg.buscador;
            document.getElementById('aud-busqueda').value = '';
            document.getElementById('aud-desde').value = '';
            document.getElementById('aud-hasta').value = '';

            let opciones = `<option value="">${escaparHtml(cfg.filtro.todos)}</option>`;
            Object.keys(cfg.filtro.opciones).forEach(k => {
                opciones += `<option value="${escaparHtml(k)}">${escaparHtml(cfg.filtro.opciones[k])}</option>`;
            });
            document.getElementById('aud-filtro').innerHTML = opciones;

            document.getElementById('aud-thead').innerHTML =
                '<tr>' + cfg.columnas.map(c => `<th>${escaparHtml(c)}</th>`).join('') + '</tr>';
            cargarAuditoriaNueva(1);
        }

        function audVal(id) { return document.getElementById(id).value; }

        function cargarAuditoriaNueva(pagina) {
            audPagina = pagina || 1;
            const cfg = AUD_VISTAS[audSub];
            const tbody = document.getElementById('aud-tbody');
            tbody.innerHTML = `<tr><td colspan="${cfg.columnas.length}" style="text-align:center; padding:2rem; color:#64748b;">Cargando registros...</td></tr>`;

            const p = new URLSearchParams({
                ajax: '1', vista: audSub, pagina: audPagina,
                fecha_desde: audVal('aud-desde'), fecha_hasta: audVal('aud-hasta'), busqueda: audVal('aud-busqueda').trim()
            });
            if (audVal('aud-filtro')) p.set(cfg.filtro.param, audVal('aud-filtro'));

            fetch('dashboard.php?' + p.toString(), { credentials: 'same-origin' })
                .then(r => r.json())
                .then(res => {
                    if (!res.success) throw new Error(res.error || 'No se pudieron obtener los registros.');
                    if (res.data.length === 0) {
                        tbody.innerHTML = `<tr><td colspan="${cfg.columnas.length}" class="empty-state">No se encontraron registros con los criterios seleccionados.</td></tr>`;
                    } else {
                        tbody.innerHTML = res.data.map(cfg.fila).join('');
                    }
                    audPaginacion(res.total_paginas, res.pagina_actual, res.total_registros);
                })
                .catch(err => {
                    tbody.innerHTML = `<tr><td colspan="${cfg.columnas.length}" style="text-align:center; padding:2rem; color:#dc2626;">Error: ${escaparHtml(err.message)}</td></tr>`;
                });
        }

        function audPaginacion(totalPaginas, actual, totalRegistros) {
            const cont = document.getElementById('aud-paginacion');
            let html = `<span style="color:#64748b; font-size:0.85rem; margin-right:1rem;">${parseInt(totalRegistros, 10)} registro(s)</span>`;
            if (totalPaginas > 1) {
                html += `<button type="button" class="pagination-btn text-label" onclick="cargarAuditoriaNueva(${Math.max(1, actual - 1)})" ${actual <= 1 ? 'disabled' : ''}>Anterior</button>`;
                for (let p = 1; p <= totalPaginas; p++) {
                    html += `<button type="button" class="pagination-btn ${p === actual ? 'active' : ''}" onclick="cargarAuditoriaNueva(${p})">${p}</button>`;
                }
                html += `<button type="button" class="pagination-btn text-label" onclick="cargarAuditoriaNueva(${Math.min(totalPaginas, actual + 1)})" ${actual >= totalPaginas ? 'disabled' : ''}>Siguiente</button>`;
            }
            cont.innerHTML = html;
        }

        function limpiarFiltrosAud() { cambiarSubAuditoria(audSub); }

            const fila = document.getElementById('aud-det-' + id);
            if (fila) fila.style.display = (fila.style.display === 'none') ? 'table-row' : 'none';
        }

 -- Todo lo que hizo un usuario hoy
 SELECT fecha_hora, accion, entidad, id_registro, descripcion
 FROM auditoria_cambio
 WHERE dni_usuario = '87654321' AND fecha_hora >= CURRENT_DATE
 ORDER BY fecha_hora DESC;

 -- Historia completa de un registro (quién lo tocó y cómo)
 SELECT fecha_hora, dni_usuario, accion, datos_anteriores, datos_nuevos
 FROM auditoria_cambio
 WHERE entidad = 'insumo' AND id_registro = '24751'
 ORDER BY fecha_hora;

 -- Libro de stock de un insumo
 SELECT s.fecha_hora, s.dni_usuario, s.stock_anterior, s.stock_nuevo,
        s.origen, s.id_movimiento
 FROM auditoria_stock s JOIN insumos i USING (id_insumo)
 WHERE i.codigo = '24000' ORDER BY s.id_auditoria_stock;

 -- Control de coherencia: el stock actual debe ser el último "nuevo"
 -- (solo para insumos que tengan auditoría desde su alta)
 SELECT i.codigo, a.stock_nuevo AS segun_auditoria, sa.stock_actual AS stock_real
 FROM insumos i
 JOIN stock_actual sa USING (id_stock_actual)
 JOIN LATERAL (SELECT stock_nuevo FROM auditoria_stock
               WHERE id_insumo = i.id_insumo
               ORDER BY id_auditoria_stock DESC LIMIT 1) a ON TRUE
 WHERE a.stock_nuevo <> sa.stock_actual;
 -- (si devuelve filas, alguien cambió el stock sin pasar por el sistema)

 -- Ingresos fallidos por IP en los últimos 7 días
 SELECT ip, count(*) AS intentos, count(DISTINCT dni) AS dnis
 FROM auditoria_acceso
 WHERE evento IN ('LOGIN_FALLIDO','LOGIN_BLOQUEADO')
   AND fecha_hora > now() - interval '7 days'
 GROUP BY ip ORDER BY intentos DESC;

LO QUE LA AUDITORÍA NO CUBRE (límites conocidos)
---------------------------------------------------------------------
   * Cambios hechos DIRECTAMENTE en la base (pgAdmin, psql, scripts): no
     pasan por el sistema, así que no quedan registrados. La consulta de
     coherencia de arriba sirve para detectar cambios de stock hechos así.
   * Datos anteriores a la puesta en marcha: la auditoría empieza vacía.
     Los insumos que ya existen no tienen registro de "alta"; su libro de
     stock empieza con el primer cambio posterior. (Opcional: cargar una
     fila ALTA_INSUMO por cada insumo existente con su stock del día.)
   * Cierre de sesión por vencimiento o cierre del navegador.
   * Consultas y lecturas (quién miró qué): no se registran.
   * La tabla vieja "herramienta" (anterior a que el estado pasara a
     insumos) no se audita: ya no se usa desde las pantallas.
   * La auditoría crece sin límite (no se puede borrar). Para un taller
     es muy poco volumen; si algún día molesta, se puede particionar por
     año o archivar con un proceso del administrador de la base.
